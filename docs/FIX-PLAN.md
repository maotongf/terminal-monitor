## 目标与约束

- 一眼看清正在进行、需要用户处理、已完成和异常的任务。
- 状态、阶段和最近回复来自正确的 Codex 会话与本轮任务；阶段概括与原始消息分开，缺失内容隐藏，不猜测完成百分比。
- 点击任务直接跳转；有真实关联的完成任务继续使用原终端。兜底关联可纠正，不能冒充已确认的原始终端。
- 界面简洁、颜色克制、浅色/深色主题均协调；颜色之外保留文字与必要图标。
- 仅大分组可折叠，不恢复每条任务的折叠开关。悬浮卡片可移入、停留、滚动和复制。
- 分批实施，每批记录版本、提交、验证结果与遗留问题；真实窗口和主题验收单独记录。

## 状态标签与配色方案

采用“低饱和背景 + 清晰文字 + 必要状态图标”的胶囊标签。行背景保持中性，状态色集中用于标签和小图标，避免整行大面积彩色。相同状态在列表、悬浮、统计中使用同一语义。

| 状态 | 中文显示 | 色彩语义 | 辅助形态 | 说明 |
| --- | --- | --- | --- | --- |
| Running / Active | 进行中 | 蓝色 | 活动圆点 | 表达正在执行，不使用成功绿色 |
| Completed / Done | 已完成 | 绿色 | 对勾 | 与进行中明确区分，完成后停止计时动画 |
| Waiting on approval/input | 待你处理 | 琥珀色 | 提示图标 | 用户需要操作；悬浮中显示待批准或待输入的具体原因 |
| Waiting on external tool | 等待工具 | 紫色 | 等待图标 | 不计入“待你处理” |
| Failed | 失败 | 红色 | 错误图标 | 优先展示失败原因 |
| Quiet | 暂无输出 | 次要灰色 | 空心圆 | 仅代表终端暂时没有输出，不等于完成或失败 |
| Idle | 空闲 | 次要灰色 | 小圆点或无图标 | 保持低视觉权重 |
| Interrupted | 已中断 | 次要灰色 | 停止图标 | 不与失败混为一类 |
| Unknown | 未知 | 次要灰色 | 问号 | 不伪装为空闲或正常运行 |
| Disconnected / Stale | 连接中断 / 数据过期 | 琥珀色提示 | 连接图标 | 属于连接状态，保留任务最后状态并注明过期 |

颜色以主题语义变量和集中定义的状态色变量实现，并提供后备值。蓝、绿、琥珀、紫、红的具体色值在实际浅色/深色主题预览后确定，不把一组固定颜色用于所有主题。默认不使用闪烁或持续呼吸动画。高对比度主题使用明确边框和可读文字，不能只靠半透明背景。
